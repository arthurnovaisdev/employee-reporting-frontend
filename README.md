# Ouvidoria Interna - Frontend

Frontend de uma aplicação corporativa de ouvidoria interna e canal de denúncias, desenvolvida para oferecer uma interface simples, segura e intuitiva para colaboradores e administradores.

A aplicação foi construída com **React e TypeScript** e possui integração completa com uma API desenvolvida em Java + Spring Boot.

O sistema permite que colaboradores registrem denúncias, enviem anexos, recebam protocolo e código de acompanhamento e consultem posteriormente o andamento da manifestação.

Administradores possuem acesso a um painel próprio para gerenciamento de denúncias, usuários, categorias e status.

## Tecnologias

- React
- TypeScript
- Vite
- Material UI
- React Router
- Axios
- React Query
- React Hook Form
- Zod

## Principais funcionalidades

- Login
- Primeiro acesso e alteração de senha
- Registro de denúncias
- Upload de anexos
- Geração de protocolo
- Consulta de protocolo
- Acompanhamento de status
- Painel administrativo
- Gerenciamento de usuários e categorias
- Interface responsiva
